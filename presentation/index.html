Graphical Abstract: The Path Through the Swamp

The Swamp of the Dead: GRUD \(P_{CO2}\) Model

The GRUD assumes that correcting a P-deficit requires a simple linear multiplier \(C\), mapping continuous soil variables into rigid, discrete steps (\(C: \mathbb{R}^2 o \mathbb{Q}\)).

The Swamp of the Dead: GRUD \(P_{AAE10}\) Model

By applying the exact same affine mathematical structure to an aggressive extractant (\(AAE10\)), the GRUD implicitly assumes a linear correlation with \(CO_2\), completely ignoring the complex, non-linear dissolution kinetics of solid mineral phase Phosphorus.

The GRUD-model

The GRUD model assumes the soil’s buffer power is constant (\(Q = b \cdot I\)). This ignores the profound chemical turning point at low saturations (\(I < 1 \text{ mg/L}\)).

safe_points = active_sites.map(site => {
  let K = site.K;
  let n = site.n;
  let threshold = -1.0; // curvature threshold where linear assumption is "ok"
  let I_safe = Math.pow(threshold / (K * n * (n - 1)), 1 / (n - 2));
  let Q_safe = K * Math.pow(I_safe, n);
  return { I: I_safe, Q: Q_safe, name: site.name };
})

Physical Chemistry over Agronomic Correlation

  • The Problem: Heavy Ca, Mg, and K treatments artificially increase the ionic strength (\(I\)) of the soil solution, confounding raw mass extractions (\(P_{CO2}\)).
  • The Solution: We convert raw mass into thermodynamic effective concentration (\(a_{CO2}\)) via the Davies equation.
  • The Metric: Absolute P-Uptake (Yield \(\times C_P\)), which reflects true physical mass flux, bypassing the Piper-Steenbjerg effect.

The Q(I) Curve & Physical Buffer Power (\(b\))

The availability of Phosphorus is strictly dictated by the dynamic phase equilibrium: \[ Q(I) = K \cdot I^n \] Where \(b = dQ/dI\) represents the true pedochemical buffer power supplying the root sink.
