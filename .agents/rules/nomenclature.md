# Nomenclature Standardization

All text generated, code written, and diagrams produced in this workspace MUST strictly adhere to the following LaTeX/MathJax nomenclature for variables. We are pedantic about this. 

In markdown text, single-escape the `\text{}` commands (e.g. `$P_{\text{up}}$`).
In R scripts inside strings (e.g., for `kable`), double-escape the `\text{}` commands (e.g. `"$P_{\\text{up}}$"`).

- **Relative Yield**: `$Y_{\text{rel}}$`
- **Total P Uptake**: `$P_{\text{up}}$`
- **Relative P Uptake**: `$P_{\text{up, rel}}$`
- **P Balance**: `$P_{\text{bal}}$`
- **Empirical Quantity (AAE10)**: `$P_{\text{AAE10}}$`
- **Empirical Intensity (CO2)**: `$P_{\text{CO}_2}$`
- **Desorbable P**: `$P_{\text{desorb}}$`
- **Amorphous Aluminum Oxide**: `$Al_{\text{ox}}$`
- **Amorphous Iron Oxide**: `$Fe_{\text{ox}}$`
- **Temperature Anomaly**: `$T_{\text{anom}}$`
- **Precipitation Anomaly**: `$Pr_{\text{anom}}$`
- **Nitrogen Fertilizer**: `$N_{\text{fert}}$`
- **Desorption Rate Constant**: `$k_{\text{des}}$`
- **Initial Desorption Velocity**: `$v_{\text{des}}$`
